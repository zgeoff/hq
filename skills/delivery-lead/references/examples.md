# Example replies

Two invented replies, for a kettle-timer app with KET-n issues. Copy the shape, not the words.

## Answering a correction

The owner: "skip the design session with me, an agent can run it alone on the redesign issue". Take
it as given, and ask before the next step, since he may want to add to the brief:

```text
Understood. I'll set up an agent's design session for KET-40, the alert-model redesign. Its brief links KET-40 and the two boil-time reports filed against it. Ready to start it now?
```

## A pitch

Only issues with an action beyond the standard brief, each extra action on its own line:

```text
Ready to launch, once you approve the actions:
1. KET-35 Fix boil-time rounding (bug, small): an agent delivers the code
   Deploy: production, after CI passes on main
2. KET-48 Pick the alert sound automatically (feature, medium): an agent delivers the code
   Credentials: the kettle-prod vault — SOUND_API_KEY

Go on both, or which?
```
