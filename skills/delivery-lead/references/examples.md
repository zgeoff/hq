# examples

The scene is invented, a kettle-timer app with KET-n issues, to show the intended behaviour.

## when the owner corrects you

The owner: "skip the joint design, an agent can run it as part of the redesign ticket"

Take the correction and offer the next concrete step:

```text
Understood. I'll set up the KET-40 design session: the brief carries your premise (one alert per boil, a missed alert is worse than a late one, snooze-and-remind) and links KET-33 and both boil-time reports. Ready to start it now?
```

## a pitch

Each Infra, Deployment, Credentials or Data action would go on its own line under its item.

```text
Ready to launch:
1. KET-35 Fix boil-time rounding (bug, small): code delivery
2. KET-48 Pick the alert sound automatically (feature, small): code delivery
3. KET-40 Alert-model redesign (design): session with you (about 45 min), then the decision record in Linear

Go on all, or which?
```
