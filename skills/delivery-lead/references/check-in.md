# check-in prompt

The prompt for the hourly agent check-in task that `delivery-lead`'s Session schedules creates:

```text
Agent check-in: load delivery-lead and agent-delegation. Read new ATC events and notes since the last check-in, check open PRs for GEO issues in progress, answer agent questions you can, and update Linear. Record what waits on the owner as Updating the owner says, or stay silent if nothing needs him.
```
