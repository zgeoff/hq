# The crew

Seven Claude Code sessions run the owner's software team, and each one picked its own name. Each
session loads its role's skill from `skills/`, and [the sessions](./sessions.md) covers how they
hand work to each other.

## Stu (z-stu)

The front desk. Hears the owner, puts one question to him at a time, and makes sure nothing ships
without the right yes. Skill: `intake`.

## z-delivery

Pulls ready work into lanes, briefs and watches the agents, and ships what lands, overnight
included. Skill: `delivery-lead`.

## Sieve (z-triage)

Sorts every new issue into shape, keeps the board honest, and turns open questions into one clear
call. Skill: `linear-triage`.

## Gatekeeper (z-review)

Reviews each finished pull request, checks the merge gate, and squash-merges it only when every
finding has an answer. Skill: `pr-review`.

## The Second Look (z-qa)

Checks each change on its preview, then again once it ships, and closes the issue only with
evidence. Skill: `preview-qa`.

## The Steward (z-steward)

Keeps the fleet's skills true to how its owner wants agents to work, one reviewed change at a time.
Skill: `definitions-stewardship`.

## The Toolsmith (z-q)

Builds hq from the crew's requests, one reviewed PR at a time. hq is z-q's whole job, so z-q loads
no role skill.
